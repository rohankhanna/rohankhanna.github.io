Local-first command-line tools

Command-line tools that run on your own machine, for device security, model routing, credential custody and agent workflows. Each one is a single installable program with no service to sign up for.

The projects

posture

posture assesses a device's security posture and marks what it could not assess.

atelier

Repository

callosum

Callosum records every model request it routes — backend, status, token counts and quota meters before and after — in a local SQLite log.

Repository

prior_art

Install a required research step into a repository, and fail when the evidence is missing.

Repository

update-all

update-all updates your workstation by default and only reports the risky updates until you ask.
